# Точка зрения — блог

Небольшой блог на PHP 8.1+, MySQL и Smarty без PHP-фреймворков.

## Запуск через Docker

Нужны Docker и Docker Compose.

1. Соберите и запустите контейнеры из корня проекта:

   ```
   docker compose up --build -d
   ```

2. Заполните базу демонстрационными категориями и статьями:

   ```
   docker compose exec app php bin/seed.php
   ```

3. Откройте [http://localhost:8080](http://localhost:8080).

Сидер безопасно запускать повторно: он обновляет демонстрационные статьи и категории и приводит связи статей к заданному
набору. Счётчики просмотров при повторном запуске сохраняются. В базе должны быть таблицы, описанные в
`database/schema.sql`; сидер создаёт их, если их ещё нет.

Для подключения без Docker задайте переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` и `DB_PASSWORD`,
установите зависимости Composer и запустите сидер командой `php bin/seed.php`. Публичная директория сайта — `public/`.

## Возможности

- Главная показывает категории, в которых есть статьи, и три последние статьи каждой категории.
- Страница категории поддерживает сортировку по дате и просмотрам, а также постраничный вывод.
- Страница статьи показывает материал, увеличивает счётчик просмотров и выводит похожие статьи из общих категорий.
- Демонстрационные иллюстрации хранятся в `public/assets/images/`; в базе сохраняются пути к ним.

## Структура

- `src/Controller` — обработчики страниц.
- `src/Service` — логика приложения.
- `src/Repository` — запросы к MySQL через PDO.
- `src/View` и `views/` — Smarty и шаблоны.
- `database/schema.sql` — структура базы данных.
- `bin/seed.php` — создание таблиц и заполнение демонстрационными данными.

## Тестовое задание

Необходимо разработать простой, но полностью рабочий веб-сайт на чистом PHP (без фреймворков) с использованием MySQL и
шаблонизатора Smarty. Сайт должен реализовывать функционал блога с категориями и постами.

Технологический стек:
- PHP 8.1+
- Шаблонизатор Smarty
- База данных MySQL
- Не использовать фреймворки

Структура данных:

Категория:
- Название
- Описание
  
Статья:
- Изображение
- Название
- Описание
- Текст
- Категория (одна или несколько)
- Кол-во просмотров

Обязательные страницы:

Главная страница:
- Вывести каждую категорию, в которой есть статьи и отобразить 3 последних поста (по дате публикации).
- Вывести кнопку “Все статьи” для каждой категории.

Страница категории:
- Вывести название, описание, список статей
- Реализовать сортировку статей (по кол-во просмотров, по дате публикации)
- Реализовать пагинацию

Страница статьи:
- Вывести всю информацию о статье
- Вывести блок из 3 похожих статей

Дополнительный функционал:

Реализовать функционал для сидинга категорий и статей
